# Threepole Custom

Personal custom build of Threepole for Destiny 2.

## Custom features

- Activity name display
- Configurable activity-name auto hide
- Per-activity daily clear counter
- Raid/Dungeon activity icon
- Support for additional Raid/Dungeon activity detection
- Custom Eager Edge app icon
- Automatic updater disabled

Based on Threepole by des-sh.
